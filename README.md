# Buffalo Plains Adventures

Buffalo Plains Adventures is a premium Kenya safari and adventure booking platform showcasing curated wildlife safaris, luxury lodges, and tailored adventure experiences across Kenya.

---

## Vision

To deliver a premium, trustworthy booking experience for travellers seeking authentic and sustainable Kenya safari and adventure packages.

---

## 🚀 Features

- 🗺️ Browse curated destinations and travel experiences across Kenya  
- 📸 Destination highlights with descriptions and visual previews  
- 🌍 Intuitive UI for exploring locations geographically and categorically  
- 📌 Easy link navigation to detailed destination info  
- 📂 Structured project codebase for scalability and enhancement

## 🛠️ Installation

To run this project locally:

1. **Clone the repo**

    ```bash
    git clone <your-repo-url>
    cd buffalo-plains-adventures
    ```

2. **Install dependencies** (if applicable)

    ```bash
    # For Node.js
    npm install
    ```

3. **Run locally**

    ```bash
    npm install
    npm run dev
    ```

4. **View in browser**

    ```
    http://localhost:5173
    ```
